**Author:** Selam Belete

## Project Description

Garden Simulation is an interactive game built with Python and Pygame. The player takes care of a plant by providing water and sunlight. As the plant receives proper care, it progresses through different growth stages from a seed to a fully grown flower. The project combines user interaction, animations, sound effects, and visual feedback to create a simple but engaging simulation.

## Features

- Home screen with Start button
- Multiple plant growth stages
  - Seed
  - Growing Plant
  - Fully Grown Flower
- Water and sunlight care system
- Health, water, and sunlight status bars
- Animated flower movement
- Interactive buttons with hover effects
- Sound effects for player actions
- Reset functionality

## Technologies Used

- Python
- Pygame

## How to Run

1. Install Python.
2. Install UV if needed.
3. Clone or download this repository.
4. Open a terminal in the project folder.
5. Run:

```bash
uv run main.py
```

## Controls

| Button | Action |
|---------|---------|
| Start | Begin the simulation |
| Water | Water the plant |
| Sunlight | Give sunlight to the plant |
| Reset | Restart the simulation |
